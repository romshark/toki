# AI coding agents

`toki generate` writes skills that teach AI coding agents, such as Claude Code and Codex, to use Toki in your module:

| Skill | What an agent reads it for |
| --- | --- |
| `toki` | Writing, changing and removing TIKs: placeholders and the argument types they take, translator comments, contexts, domains, the bundle package and the errors that `toki generate` reports. |
| `toki-translate` | Translating the catalogs: blank and incomplete messages, plural options, new languages and the plural forms of the default locale. |

It writes each skill to 2 places in the root of the module, next to `go.mod`:

- `.claude/skills/<skill>/SKILL.md`, where Claude Code finds skills.
- `.agents/skills/<skill>/SKILL.md`, where Codex and other agents find them.

The skills name the bundle package of your module, its import path and its default locale. They add `-b` to the commands they show when the bundle package isn't `tokibundle`. A release of Toki also names its version in them, and agents then run the version that generated the bundle.

Commit the skills. The agents of everyone working on the module then read them.

## Toki owns the skill files

`toki generate` rewrites a skill whenever it differs from what Toki writes, as after an upgrade of Toki. Don't edit the skills: `toki generate` drops your edits. Below its frontmatter, each skill starts with the comment:

```html
<!-- Generated by github.com/romshark/toki. DO NOT EDIT. `toki generate` rewrites this file unless run with `-ai-skills=false`. -->
```

To give agents instructions of your own, write a skill with another name, as `.claude/skills/i18n-style/SKILL.md`. Toki only writes `toki` and `toki-translate`.

`toki lint` and `toki edit` don't write the skills.

## Turn the skills off

Run `toki generate` with `-ai-skills=false`:

```sh
toki generate -ai-skills=false
```

Pass the flag on every run, as in a `//go:generate` directive or a script: without it, `toki generate` writes the skills again. It leaves the skills that an earlier run wrote as they are. Delete them to remove them.

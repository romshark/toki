# Bundle files

`toki generate` writes the bundle package, `tokibundle/` by default:

- `bundle_gen.go` contains Toki's core source code and package API.
  - **Not editable** 🤖 Any manual change is always overwritten.
- `catalog_<locale>_gen.go` contains the localized catalog and message writers.
  - **Not editable** 🤖 Any manual change is always overwritten.
- `catalog_<locale>.arb` is an app resource bundle file containing translations in the ICU message format.
  - **Editable** 📝 See [Editing translations](#editing-translations).
  - A new message is added automatically: in the catalog of the default locale with the ICU message that Toki generates from the TIK, and blank in the other catalogs.
  - A message that the source code no longer uses is removed from every catalog.
- `head.txt` is a text file defining the head comment to use in generated files.
  - **Editable** 📝 If this file isn't found, `toki generate` creates an empty one. Use it for copyright notices and similar purposes.
  - Write plain text: Toki starts each line with `// ` and adds it below the header of each generated `.go` file.

`<locale>` is the locale in lowercase, with `_` in place of `-`, as `catalog_pt_br.arb` for `pt-BR`.

## Editing translations

You may edit every message in the catalogs of other locales than the default one.

In the catalog of the default locale, the TIK determines most messages. You may edit only messages that the TIK leaves incomplete, as English plurals that need a `one` option besides `other`. Change any other message through its TIK in the source code. Keep the placeholder metadata of each message as Toki writes it.

> [!WARNING]
> `toki generate` and `toki lint` fail with "bundle contains corrupt native-locale messages" when a message in the catalog of the default locale disagrees with its TIK. `toki repair` rewrites such messages from their TIKs.

## Other files

`toki generate` keeps all other files in the bundle package. When the version of Toki changes, it first deletes every file in the bundle package and its subfolders whose first line starts with the header of generated files:

```go
// Generated by github.com/romshark/toki. DO NOT EDIT.
```
